SeismicShield-RL

Multi-agent reinforcement learning benchmark for multi-objective seismic damper co-design.

Faramarz Kowsari · Author · Software Engineer · AI Researcher

Research boundary: this project does not certify structural safety or prescribe retrofit work. v0.1 uses a synthetic research surrogate and carries no paper-level efficacy claim.

Research question

Can story-level agents improve the held-out cost–drift–acceleration Pareto frontier under unseen earthquake and structural uncertainty?

Track A

Physics, OpenSees parity, baselines, MARL, ablation, uncertainty and frozen evidence.

Track B

Interactive simulator, API and scenario explorer. UI never creates primary evidence.

Reproducibility

Frozen configs, equal-budget baselines, paired worlds, artifacts, hashes and evidence ledger.

Stage gates

v0.2: OpenSees parity → v0.3: benchmark/MARL → v0.4–0.6: scale, OOD, ablations → v0.8: confirmatory freeze → v1.0: DOI + paper.
