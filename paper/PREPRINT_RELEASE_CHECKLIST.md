# engrXiv preprint release checklist

- [ ] manuscript is an engineering research paper, not a repository description
- [ ] every numerical claim is generated from frozen evidence artifacts
- [ ] every cited source has been manually verified by the author
- [ ] AI/tool usage disclosure conforms to current engrXiv policy
- [ ] no machine-generated paragraph is submitted verbatim without human authorship/revision
- [ ] no synthetic/pilot result is presented as confirmatory evidence
- [ ] OSF preregistration DOI is cited
- [ ] Zenodo v1.0 software/evidence DOI is cited
- [ ] code and data availability statement is complete
- [ ] author ORCID is included
- [ ] conflict/funding statements are accurate
- [ ] limitations include simulator fidelity, model-form uncertainty and external-validity limits
- [ ] PDF metadata title/author match submission metadata
- [ ] supplements contain only distributable material
- [ ] repository release, evidence manifest and preprint all cross-link correctly
